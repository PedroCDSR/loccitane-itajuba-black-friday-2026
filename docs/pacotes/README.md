# Entrega de assets — sprites e Itajubá

- `sprites-nativos.zip`: 12 PNGs e manifesto de exploradora/capivara/objetos. Pedro não alterado.
- `cidade-entardecer.zip`: 13 PNGs e manifesto da cidade.
- `validacao-assets.json`: 25 PNGs aprovados nas verificações de dimensões, alfa0/255, base/opacidade e emendas das três peças repetíveis.

Pastas de uso: public/assets/sprites-nativos e public/assets/cidade-entardecer. Documentação detalhada em cada pasta. Artes-fonte em references/gerados-pacote. Os arquivos são assets preparados, não uma alteração do gameplay. Não se apresenta geração de imagens como animação já homologada; escala/head consistency e continuidade exigem revisão visual no jogo.
